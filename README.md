# GameMath
"이득우의 게임수학" 책 공부 + 실습 내용

CMake 3.22.1 버전에서 실행

### 6장 아핀 공간
- 아핀 공간 : 벡터공간의 선형변환을 행렬곱으로 구현하기 위해 차원을 하나 더 늘려서 값을 1로 한정한 부분 공간.
- 아핀 변환
  - 크기 변환 : [[a 0 0] [0 b 0] [0 0 1]] • [x y 1] = [ax by 1]
  - 회전 변환 : [[cosθ -sinθ 0] [sinθ cosθ 0] [0 0 1]] • [x y 1] = [cosθx-sinθy sinθx+cosθy 1]
  - 이동 변환 : [[1 0 a] [0 1 b] [0 0 1]] • [x y 1] = [x+a y+b 1]
