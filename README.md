# GameMath
"이득우의 게임수학" 책 공부 + 실습 내용

CMake 3.22.1 버전에서 실행

### 8장 텍스처 메핑
- **텍스처** : 메시에 이미지를 입히기 위해 변환된 데이터
- **덱스처 메핑** : 메시에 이미지를 입히는 작업
- 이미지는 픽셀 수에 따른 고유의 해상도를 가진다. --> 이를 [0,1]범위로 정규화 하여 사용한다. 이 때 2차원 좌표계를 **UV좌표계**라고 한다.
- 텍스처 매핑 방법 =>
  1. 삼각형을 구성하는 각 필셀의 무게중심좌표 계산
  2. 해당 정점의 UV좌표와 선형보간 --> 해당 픽셀의 UV값을 얻을 수 있음  (정점 버퍼에 UV 좌표 데이터가 있을 것!)
  3. UV값에 대응되는 텍스처의 색상 정보를 픽셀의 생상으로 지정하면 끝!
