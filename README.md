# GameMath
"이득우의 게임수학" 책 공부 + 실습 내용

CMake 3.22.1 버전에서 실행

### 5장 행렬
- 역행렬을 이용하여 변환된 행렬을 다시 원래 형태로 되돌린다.
- 크기 변환행렬, 회전 변환행렬, 전단 변환행렬 세 가지 종류가 있다.
- 크기 변환행렬의 역행렬은 배율을 되돌리기 위해 크기 변환행렬의 원소에 역수를 대입해준다.
- 회전 변환행렬의 역행렬은 회전시킨 각도만큼 다시 되돌리기 위해 각도 부호를 바꿔준다. 삼각함수의 성질에 의해 부호가 결정되는데, 이 때 행렬의 관점에서 보면 전치연산을 적용한 것과 같다. (각도의 부호와 상관없는 cos이 대각선 영역에 있고, sin만 부호가 바뀌기 때문.)
- 전단 변환행렬의 역행렬은 민 크기만큼 되돌려야 하므로 이에 영향을 미친 원소에만 부호를 바꿔준다.
- 마지막으로 역행렬들을 곱하기 전에, 행렬곱에서 역을 취한 모양을 생각해야 한다. 이 때 분배법칙이 성립하지 않으므로 역순으로 곱해주어야 한다.
