# GameMath
"이득우의 게임수학" 책 공부 + 실습 내용

CMake 3.22.1 버전에서 실행

### 8장 삼각형
- 선은 두 점으로 표현. 삼각형은 세 점으로 표현 --> 두 스칼라 값이 필요함. (두 벡터가 선형 독립이라면 다른 벡터는 모든 점을 표현할 수 있다.)
## 와이어프레임
- 메시 --> 2차원과 3차원에서 모두 삼각형으로 문체표현 가능 (3차원은 표면만 그리면 되기 때문)
- 삼각형도 결국 3개의 점으로 구성됨 --> 각 정점의 위치를 저장하는 배열 **정점 버퍼**, 각 정점들을 구분하면서 삼각형의 구성을 표현하는 **인덱스 버퍼**
