# GameMath
"이득우의 게임수학" 책 공부 + 실습 내용

CMake 3.22.1 버전에서 실행

### 7장 내적:벡터 공간의 분석과 응용
- 벡터의 내적은 두 벡터의 사잇각의 cos값과 같다!
- 벡터의 내적은 행렬 곱으로 표현이 가능하다!
- 따라서 시야판별과 같은 곳에 사용할 수 있다
  - 플레이어가 바라보고 있는 벡터와 목표물을 향하는 벡터를 내적하면 다음과 같은 걸과를 얻을 수 있다.
    - 양수 : 플레이어의 앞에 있다 (cos-90° ~ cos90° 일 때 양수이기 때문)
    - 음수 : 플레이어의 뒤에 있다
    - 0 : 플레이어의 옆에 있다
  - 원하는 각도의 cos값을 미리 구해두면, 해당 값과 내적값을 비교하여 시야에 있는지 없는지를 알 수 있다.
